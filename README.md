# AI-316 Lab 01 — Foundations of AI Engineering & Project Setup

## Course

**AI Project Design and Development (AI-316)**
Air University Islamabad
Faculty of Computing & AI

## Lab Objective

This lab focuses on setting up a standardized AI engineering project environment and introducing basic Git-based version control.

## Project

**Semantic Machine Learning Based LLM Prompt Security Detector**

The project aims to develop a semantic machine learning security layer that detects potentially malicious prompts before they are passed to a Large Language Model (LLM).

## Tasks Completed

* Created a standardized AI project directory structure.
* Created a Python virtual environment for the project.
* Installed and verified required AI/ML libraries.
* Generated a `requirements.txt` file.
* Initialized and managed the project using Git.
* Created and merged a feature branch.
* Configured a Jupyter Notebook environment.
* Verified Python, OpenCV, PyTorch, Ultralytics, Matplotlib, and NumPy.
* Documented the project problem statement and objectives.
